Write a function `biggestOfThree(a, b, c)` that returns the **largest** of three numbers.

- `biggestOfThree(1, 2, 3)` → `3`
- `biggestOfThree(9, 4, 7)` → `9`
- `biggestOfThree(5, 8, 2)` → `8`
- `biggestOfThree(-1, -5, -3)` → `-1`

If some numbers are equal, just return that value: `biggestOfThree(4, 4, 2)` → `4`.

**Please solve it with `if` and comparisons** — no `Math.max`. Practising the decision-making is the point of today's exercise!
