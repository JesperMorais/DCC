Write a function `celsiusToFahrenheit` that converts a temperature from **Celsius** to **Fahrenheit**.

The formula is:

> Fahrenheit = Celsius × 9 ÷ 5 + 32

Examples:

- `celsiusToFahrenheit(0)` → `32` (water freezes)
- `celsiusToFahrenheit(100)` → `212` (water boils)
- `celsiusToFahrenheit(-40)` → `-40` (the one temperature where both scales agree!)

The function already takes a `number` and returns a `number`.
