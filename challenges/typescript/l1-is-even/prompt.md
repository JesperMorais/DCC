Write a function `isEven` that tells you whether a whole number is **even**.

It returns `true` for even numbers and `false` for odd numbers.

- `isEven(4)` → `true`
- `isEven(7)` → `false`
- `isEven(0)` → `true` (zero counts as even)

Negative numbers work the same way: `isEven(-2)` → `true`, `isEven(-3)` → `false`.
