Write a function `initials(first, last)` that turns a first name and a last name into **initials**:
the first letter of each name, as a **capital letter**, each followed by a dot.

- `initials("Ada", "Lovelace")` → `"A.L."`
- `initials("grace", "hopper")` → `"G.H."` (lowercase names still give capital initials)
- `initials("Linus", "torvalds")` → `"L.T."`

You can assume both names have at least one letter.
