The classic! Write a function `fizzBuzz(n)` that returns an **array of strings**, one for each number from **1 to `n`**:

- if the number is divisible by **3 and 5** → `"FizzBuzz"`
- else if it's divisible by **3** → `"Fizz"`
- else if it's divisible by **5** → `"Buzz"`
- otherwise → the number itself, as a string (e.g. `"7"`)

Examples:

- `fizzBuzz(5)` → `["1", "2", "Fizz", "4", "Buzz"]`
- `fizzBuzz(15)` ends with `"FizzBuzz"`
- `fizzBuzz(0)` → `[]`
