Write **two** small functions.

**`shout(text)`** returns the text in UPPERCASE with one `!` added at the end:

- `shout("hello")` → `"HELLO!"`
- `shout("Good Morning")` → `"GOOD MORNING!"`

**`whisper(text)`** returns the text in lowercase with `...` added at the end:

- `whisper("HELLO")` → `"hello..."`
- `whisper("Be Quiet")` → `"be quiet..."`

Both functions are already written for you with the right types — you only need to replace what they `return`.
