A maths-practice app prints a row of the times table for a child to fill in. Write `times_table(n, count)` that returns a list with the first `count` multiples of `n`, starting at `n × 1`.

- `times_table(3, 4)` → `[3, 6, 9, 12]`
- `times_table(7, 1)` → `[7]`
- `times_table(5, 0)` → `[]`

`n` can be any whole number, including `0` or a negative number.
