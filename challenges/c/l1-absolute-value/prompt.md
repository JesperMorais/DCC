Write a function `distance_from_zero` that takes an `int` and returns how far it is from zero. That's the number without its minus sign.

- `distance_from_zero(7)` → `7`
- `distance_from_zero(-7)` → `7`
- `distance_from_zero(0)` → `0`

`n` is always between `-1000000` and `1000000`.

Don't use the library function `abs()` — write the logic yourself. It's a single `if`.
