Write a function `countVowels(text)` that returns how many **vowels** are in the text.

The vowels are `a`, `e`, `i`, `o`, `u` — count both lowercase **and uppercase** ones.

- `countVowels("hello")` → `2`
- `countVowels("TypeScript")` → `2` (only `e` and `i` — `y` doesn't count)
- `countVowels("AEIOU")` → `5`
- `countVowels("")` → `0`
